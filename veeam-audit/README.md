# Аудит резервного копирования Veeam — что здесь лежит

Всё в одной папке, оба генератора читают данные отсюда и перезаписывают результат здесь же.
Источник фактов — выгрузки консолей Veeam (`VeeamDump_*`), а не документация.

## Готовые файлы

| Файл | Что это |
|---|---|
| `Схема_бэкапов_Veeam.drawio` | Схема движения копий для draw.io / app.diagrams.net: источники → консоли Veeam → хранилища → offsite, с фактическими цифрами и цветами статусов |
| `Аудит_бэкапов_Veeam_2026-10-07.xlsx` | Отчёт, 14 листов. Лист `01_Матрица` — 12 колонок по ТЗ, `02_Сводка` — блок «как объяснить руководству», `13_Справочник` — словарь колонок и терминов |
| `Матрица_и_план_проверки_бэкапов.xlsx` | Прежняя матрица аудита (входные данные для листов «вне Veeam») |
| `hosts-checklist.md` | Чек-лист 77 хостов инфраструктуры для сверки покрытия |
| `README.md` | Инструкция, как снять выгрузку с консоли Veeam вручную |

## Скрипты

| Файл | Что делает |
|---|---|
| `VeeamBackup.ps1` | Снимает данные с консоли Veeam в папку `VeeamDump_<дата>_<время>`. Запускать на каждом Veeam: `powershell -ExecutionPolicy Bypass -File VeeamBackup.ps1` |
| `build-audit-xlsx.py` | Собирает xlsx-отчёт из всех `VeeamDump_*`: `python3 build-audit-xlsx.py` |
| `build-veeam-scheme-drawio.py` | Собирает схему draw.io из тех же выгрузок: `python3 build-veeam-scheme-drawio.py` |
| `collect-veeam.ps1`, `collect-vcenter-vms.ps1` | Запасные варианты сбора, если основной отработал с ошибками |

## Как обновить после починки

1. На каждом Veeam заново запустить `VeeamBackup.ps1` (появится новая папка `VeeamDump_*`; старые можно удалить).
2. На этой машине: `python3 build-audit-xlsx.py && python3 build-veeam-scheme-drawio.py`.
3. Сверить ключевые цифры в `02_Сводка`: успешных запусков, «без актуальной копии», диски в риске.

## Известные ограничения данных

- Время запуска в старых выгрузках не зафиксировано (в `VeeamBackup.ps1` это уже исправлено). Пока нет новой выгрузки, в отчёте время подставляется по фактическим запускам из журнала.
- Привязка «задание → репозиторий» в выгрузках не читается (ошибка `GetTargetStorages`) для части заданий — в отчёте такие строки помечены и требуют ручной проверки в консоли.
- Размеры бэкапов (`09-BackupSizes.csv`) пустые — выгрузка не отдаёт их без доп. запроса.
- Список ВМ vCenter не выгружался: нет `VMware.PowerCLI` на рабочей машине. Покрытие считается по тому, что есть в репозиториях Veeam.
