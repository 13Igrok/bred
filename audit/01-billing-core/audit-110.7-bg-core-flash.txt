3. КРИТИЧНЫЕ НАХОДКИ
--------------------------------------------------------------------------
  [КРИТ-1] ActiveMQ 5.15.5 (2018, /opt/activemq), OpenWire 61616 ОТКРЫТ ПО СЕТИ
           -> CVE-2023-46604 (RCE, CVSS 10.0) и др. Java идёт от root => RCE-root.
           ДЕЙСТВИЕ: обновить до 5.18.3+/6.x ЛИБО немедленно закрыть 61616 фаерволом.

  [КРИТ-2] 214 world-writable файлов и 57 world-writable каталогов в /opt/bgbilling,
           включая JSP ПЛАТЁЖНЫХ ФОРМ (0666): sberbank, gazprombank, tinkoff,
           yoomoney, qiwi, mtsbank, netpay. Любой локальный bash-юзер может внедрить
           код в платёжные формы -> кража платёжных данных / RCE в вебе.
           ДЕЙСТВИЕ: chmod убрать world-write, владелец/группа приложения, ревизия.

  [ВЫС-3]  /opt/dump.sql (дамп БД bgbilling, режим 0664) читается всеми локальными
           пользователями, включая read-only mpeshkov. ДЕЙСТВИЕ: убрать дамп с прода.

  [ВЫС-4]  TFTP tftpd-hpa с опцией --create, каталог /tftp 0777 (drwxrwxrwx).
           Запись файлов и по сети (UDP/69), и локально кем угодно.
           ДЕЙСТВИЕ: убрать --create, права каталога, ограничить доступ по сети.

  [ВЫС-5]  Java-приложения и ActiveMQ работают ОТ ROOT — нарушение least-privilege;
           любая RCE в них = сразу root. ДЕЙСТВИЕ: вынести под сервисные учётки.

  [СРЕД-6] 78 ожидающих обновлений, ВСЕ security; unattended-upgrades не установлен;
           дистрибутив Debian 11 EOL. ДЕЙСТВИЕ: обновиться, план миграции на 12/13.

  [НИЗ-7]  node_exporter (9100) без аутентификации наружу; zabbix-agent (10050)
           без ограничения Server. ДЕЙСТВИЕ: ограничить фаерволом/конфигом.
