[КРИТ-S1] БЭКАПЫ БД НЕ РАБОТАЮТ. db-backup1(160.135) и db-backup2(160.136): каталоги
   /db-backups пусты, .136 занят 2.5G/491G. Резервных копий БД по факту нет -> при
   инциденте восстанавливаться не из чего. СРОЧНО проверить задания на СУБД-серверах.

[КРИТ-S2] omicron-sudo = %omicron-sudo ALL=(ALL) NOPASSWD: ALL — ПОЛНЫЙ ROOT БЕЗ ПАРОЛЯ,
   подтверждено на 5+ хостах (160.110, 160.35, 160.31, 161.56, 161.55, 161.26, 160.19...).
   Группа раздута «мёртвыми душами»: до 16 членов (zabbix-core), 9-11 nologin-учёток
   бывших сотрудников (aglukhov, epetrov, itronin, ishatohin, userobaba, akudryaeva,
   oborovkov, obobrovkov, inebalzin, vklimansky, gmasich-test1, ousepov...).
   Кросс-доменный доступ: учётки omiplat/rocketcom/360pro имеют root везде.
   Компрометация ЛЮБОЙ = мгновенный root на десятках хостов.

[КРИТ-S3] ActiveMQ уязвим к CVE-2023-46604 (RCE 10.0) на ВСЕХ 5 bg-core, OpenWire 61616
   открыт по сети (5.15.5/5.18.1/5.15.5/5.17.3/5.17.3). Java от root -> RCE-root.

[ВЫС-S4] ВНЕШНИЕ ПОДРЯДЧИКИ С ROOT: valeriy (bitel@bgbilling.ru — вендор BGBilling) и
   sgaregin (sgaregin@example.com) в omicron-sudo на git(161.7), voice1/2(161.17/45),

   с sudo на bitrix-to-erp(161.49). atarasov(cc@cc.ru) с sudo на call-центрах.
