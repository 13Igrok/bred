1. Площадки, ядро и сегменты

Физика ядра в Wiki есть только во вложениях drawio/vsdx — пунктир означает связь, которая описана косвенно или не описана.

  • Пять операторов с отдельными AS: ЮТК AS210135, Омиплат AS48433, Рокет AS208142, Флэш AS48120, РТЦ AS43149 [103].
  • Ядро/ТСПУ — Краснодар, Комсомольская 40; офис — Российская 341/1 (192.168.156.0/24) [700].
  • Hairpin NAT на CCR2004 нет — изнутри к своим белым IP через /etc/hosts или split-DNS [52].
  • Оценка [700]: CR (MX80) загружен >80 %, «роутер на палочке» на AR неприемлем, P2P через стыковочные сети 155.40/155.41.

2. VPN

Всё входит через CCR2004 185.221.44.2; site-to-site к REG.RU — IPSec + GRE с резервом через Флэш.

  • OpenVPN отдаёт маршруты: 10/8, 100.64/10, 172.16/12, 192.168.160/23, .110, .155, .156, .61, .158 [109] — через него инженер попадает в management 10.x.
  • WireGuard-хост на CentOS 8.3 (EOL), не в Ansible; инструкция [219] с wg-quick down/up рвёт все сессии [86].
  • В REG.RU анонсируется 192.168.160.0/24, а не /23 — .161.x из облака недоступны [696].

3. Публикация сервисов: NAT 1:1 и reverse-proxy

Центральный nginx 192.168.161.6 (185.221.44.20): Let's Encrypt, GeoIP только RU, 33 vhost [49]. Остальное — прямой NAT 1:1 на CCR2004 [52].

  • Только из 192.168.0.0/16 и офиса 185.147.38.8: bg-test, bot-analys, bywin, erp-test, fop2, git, grafana, netbox, olt, pass, plan, registry.
  • ЛК/API биллингов — 2–3 слоя nginx: ядро → nginx-<оператор> 192.168.181.20–.25 (REG.RU) → фронт .161.173/.175/.176; по две A-записи (свой вход + 194.67.117.0/24) [98].
  • Исходящий прокси socks.loc = 192.168.161.12 (SOCKS5 :1080, HTTP :3128) через Hysteria2 — ERP и Zabbix для Telegram [777].

4. DNS

Split-horizon: снаружи — PowerDNS ns1/ns2, изнутри — AD DNS на DC1/DC2 с серыми адресами и зоной .loc.

  • Почта 360pro.online: MX 10 relay1 / 15 relay2; SPF ip4:185.221.44.9 ip4:185.221.44.17; DMARC p=reject; DKIM mail [40][43].
  • Из 192.168.110.0/24 внешние резолверы недоступны → авария Флэш 2026-08-31 (транк Манго, вход в биллинг 20–40 с) [772].
  • DNS для абонентов (DHCP/PPPoE/RADIUS) и владельцы зон omiplat.ru / rocketcom.ru / flash-telecom.ru в Wiki не описаны.
