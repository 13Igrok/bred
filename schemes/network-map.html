6. Единые точки отказа (карта зависимостей 360pro)

УзелПочему это точка отказа
Периметр MikroTik CCR2004 · 185.221.44.2Весь NAT (~40 сервисов), VPN, GRE до RegRu, СОРМ. Отказ = нет внешнего доступа, почты, ЛК, удалёнки
Хранение HPE MSA sv4 / sv5Обе в статусе Degraded, 136 из 170 ВМ, репликации нет: ядра биллингов, ERP, Exchange, 1С
Каталог dc1 · 192.168.160.60Все FSMO; единственный LDAPS для почты и Bitrix; DNS для площадки 110.x (телефония Flash/РТЦ)
Вход nginx · 192.168.161.6Один контейнер: ERP снаружи, SOGo и почтовые клиенты, Vault, API Gateway, GitLab, Grafana
Платформа K3s · VIP 192.168.161.101Почта 360pro, Vault, API Gateway; node5 NotReady → запас по кворуму etcd — одна нода
Приложение BGERP · 192.168.160.31Одна ВМ с локальным MySQL, без HA
RADIUS и NAS каждого биллингаПо одному боевому экземпляру; рестарт RADIUS = 5–10 мин Reject для всех абонентов оператора
vCenter 192.168.160.202 (node50)vSphere 6.7 EOL — вся виртуализация управляется одной ВМ на неподдерживаемой версии
Люди: n8n, бэкапы, MFAn8n принадлежит одному сотруднику; bus-factor по бэкапам = 1; второй фактор VPN держится на одном RADIUS MultiFactor
