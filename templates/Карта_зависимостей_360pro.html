Единые точки отказа

Отсортированы по числу сервисов, которые падают вместе с узлом.

Периметр
MikroTik CCR2004 · 185.221.44.2
Весь NAT (~40 сервисов), VPN, GRE до RegRu, СОРМ. Отказ = нет внешнего доступа, почты, ЛК, удалёнки.
Хранение
HPE MSA sv4 / sv5 · обе Degraded
136 из 170 ВМ, репликации нет: ядра биллингов, ERP, Exchange, 1С.
Каталог
dc1 · 192.168.160.60
Все FSMO; единственный LDAPS для почты и Bitrix; DNS для площадки 110.x (телефония Flash/РТЦ).
Вход
nginx · 192.168.161.6, один контейнер
ERP снаружи, SOGo и почтовые клиенты, Vault, API Gateway (бот, мобильное приложение), GitLab, Grafana.
Платформа
K3s · VIP 192.168.161.101
Почта 360pro, Vault, API Gateway. node5 NotReady: запас по кворуму etcd — одна нода.
Приложение
BGERP · 192.168.160.31
Одна ВМ с локальным MySQL, без HA.
По оператору
RADIUS и NAS каждого биллинга
По одному боевому экземпляру; рестарт RADIUS = 5–10 мин Reject для всех абонентов оператора.
Управление
vCenter .160.202 на node50, vSphere 6.7 EOL
Управление всей виртуализацией из одной ВМ на неподдерживаемой версии.
Люди
n8n, бэкапы, MFA RADIUS
n8n принадлежит одному сотруднику; bus-factor по бэкапам — 1; второй фактор VPN держится на одном RADIUS MultiFactor.
